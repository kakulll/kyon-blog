# 📖 kyon.me - 个人博客与主页

基于 **VitePress** 构建的现代化纯静态博客。

## ✍️ 写作流程 (Obsidian + GitHub)

1. 在 **Obsidian** 中打开此文件夹 (`kyon-blog`)；
2. 文章存放在 `docs/blog/posts/` 目录下（新建 `.md` 文件即可）；
3. 插入的图片建议存放在 `docs/public/uploads/`；
4. 通过 **Obsidian Git 插件** 或终端执行 `git push` 推送至 GitHub；
5. 电视盒子全自动拉取并构建上线到 **https://kyon.me**！
